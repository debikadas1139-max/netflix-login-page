# 🎬 Netflix-Inspired Front Page Clone

A Netflix-inspired front page clone created using HTML and CSS.

This project recreates the look and feel of a Netflix-style streaming platform landing page as a frontend practice project.

## 🌐 Live Demo

Coming soon...

## ✨ Features

- Netflix-inspired navigation bar
- Netflix-style hero section
- Language selection button
- Sign-in button
- Email input section
- Get Started button
- Movie and TV show themed background
- Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
